# Алгоритмы и структуры данных

**Лабораторные работы № 1–12**

Александра Асеева, группа 243-321

В репозитории представлены решения лабораторных работ на Python. Каждая работа находится в отдельном файле в каталоге [`labs/`](labs). Работы можно проверить двумя способами — локально в браузере через HTML-страницу или напрямую из файлов Python.

## Проверка в браузере

1. Скачайте репозиторий и распакуйте его, если он загружен архивом.
2. Откройте локальный файл [`index.html`](index.html) в браузере.
3. Перейдите по ссылке на нужную лабораторную и выберите задание, если в работе несколько пунктов.
4. Введите контрольные данные в поле **«Входные данные»**, соблюдая указанный порядок строк, или нажмите **«Подставить пример»**.
5. Нажмите **«Запустить»**. Вывод программы появится в разделе **«Результат»**.

Локальный веб-сервер не требуется. При первом запуске браузер загружает среду Python, поэтому необходимо подключение к интернету.

## Проверка из файла Python

Откройте терминал в корне репозитория и выполните команду для нужной работы. Например, для лабораторной № 1 используйте:

```sh
python labs/lab01.py
```

Для запуска требуется Python 3.8 или новее. В Windows также можно использовать команду `py labs/lab01.py`. Каждый скрипт запускается самостоятельно, без установки пакетов.

В работах № 1–6 сначала введите номер пункта. После результата нажмите **Enter**, чтобы проверить тот же пункт на новых данных, или введите номер другого пункта. В работах № 7–11 клавиша **Enter** запускает тот же алгоритм повторно. В работе № 12 можно последовательно вводить команды очереди. Для завершения введите `0` в подсказке меню или повтора.

При вводе данных следуйте подсказкам программы. Несколько чисел в одной строке разделяйте пробелами. Каждую строку матрицы вводите отдельно.
